费用口径

支持未出账费用（unbilled_mtd）与自然月累计费用（calendar_mtd）。原生 API 使用 UTC 自然月，按费用发生时间统计，不因付款或出账而扣减。各平台展示自己的口径，混合合计会明确标注。费用可能延迟或更正。Cloudflare 优先使用 v1 日费用接口，仅覆盖用量费用；固定套餐月费需在配置中补充，按月全额估计，不自动摊销。缺失、过期或覆盖不完整时暂停相应预算判断。历史记录是当时保存的快照，不代表最终发票。
